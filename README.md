# IIDX Arena King

beatmania IIDXのローカルアリーナで実施する、非公式大会向けの運営・スコア管理アプリです。

## 主な機能

- 最大12名の参加者登録
- 4人分の順位・獲得ポイント・選曲譜面の登録
- 参加者ごとの試合消化数表示
- 予選順位の自動集計
- 同点時の順位判定
  - 1位回数
  - 4位回数の少なさ
  - 同点者間の直接対決ポイント
- 王決定戦・中位決定戦・逆王決定戦への自動組分け
- 大会名と開催日の登録
- 過去大会の結果閲覧
- 同一譜面の再選曲警告
- PC・スマートフォン対応

## 技術構成

- React 19
- TypeScript
- Vinext / Vite
- Cloudflare Workers
- Cloudflare D1（SQLite互換データベース）
- Drizzle ORM / Drizzle Kit

Cloudflare D1には無料枠があるため、小規模な非公式大会であれば無料枠内での運用を想定できます。利用条件や無料枠の上限はCloudflare公式サイトで確認してください。

## データベース

テーブル定義は `db/schema.ts`、マイグレーションは `drizzle/` にあります。

スキーマを変更した場合は、次のコマンドでマイグレーションを生成します。

```bash
npm run db:generate
```

主なテーブルは以下のとおりです。

- `tournaments`: 大会名・開催日
- `participants`: 大会ごとの参加者
- `matches`: 予選・各順位決定戦
- `results`: 各試合の獲得ポイント・順位・選曲譜面

## 大会ルールへの対応

- 予選は1人6試合
- 予選上位4名、中位4名、下位4名でそれぞれ順位決定戦を実施
- 予選から順位決定戦まで同一譜面を再選曲不可
- 予選同点時は、1位回数、4位回数、直接対決ポイントの順で判定
- 順位決定戦同点時は予選順位を優先

## 注意事項

本アプリは非公式大会向けであり、KONAMIおよびbeatmania IIDXの公式サービスではありません。
